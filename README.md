# FURLANICH

FURLANICH is being transformed from Samuel Furlanich's personal portfolio into a bilingual, business-facing software studio website. The commercial site will become the primary experience while Samuel's professional profile and selected personal work remain available as secondary credibility content.

The authoritative product and design knowledge lives in [`docs/index.md`](docs/index.md). Current application code represents the existing implementation and must not be treated as the intended product when it conflicts with the documentation.

For engineering work, start with [`AGENTS.md`](AGENTS.md), the [architecture map](ARCHITECTURE.md), and the [engineering lifecycle](docs/governance/engineering-lifecycle.md). They route agents and contributors to requirements, decisions, plans, and deterministic validation without redefining the product.

The repository contains the **Stage A — Knowledge Migration** baseline. Application implementation has not yet been redesigned around the documented target.
