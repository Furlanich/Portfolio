Rulings
1. **`scripts/serve-static-export.mjs` and the harness test are edited.** The plan's Progress of 2026-10-10 carries "Windows production-export RSC-prefetch 404s" to Task 9, and the production spec failed on exactly that (five 404 console errors on each client navigation, seen only on Windows). RED first, then the nested-file mapping the lab servers already use. Cost if wrong: one revert; Linux and CI are unaffected, since dotted files exist there.
2. **The lazy-illustration case asserts the rule, not a viewport guess.** The first draft asserted the second illustration is not requested at load. It sits 824 px below the fold, inside Chrome's lazy-load margin, so it is fetched (one 640 px candidate). The case now asserts `loading="lazy"`, no preload hint and at most one candidate per illustration; the product was already right. Cost if wrong: none.
3. **The controlled hook is set by two production-script runs.** With both live tiers off nothing else exercises the engine, so the closure cross-check and the `enhanced` vitals variant set the test hook on SwiftShader. Closure bytes come from the emitted export; the shipped-policy and every static-preference run do not set the hook; the live runs are labelled controlled test evidence, never hardware. Cost if wrong: drop the cross-check and the enhanced variant; the byte accounting and the shipped-policy numbers stand alone.
4. **`data-connected-state` is not asserted.** It is an unconsumed internal witness (only the `suspended` CSS reads it) that is refreshed on scroll, not on Resume. Pause and Resume are asserted by the session flag, `aria-pressed` and counted WebGL `clear` calls. Cost if wrong: none.
5. **A rejected engine import is allowed the bundler's own re-fetch.** An aborted two-chunk closure produced four requests in the first 1.6 seconds (each chunk once more), then none; the page never retries. The case waits for the count to settle, then requires it to stay flat and to be at most twice the closure size. Cost if wrong: none.
6. **`CONNECTED_LIVE_POLICY` stays `{ wide: false, compact: false }`.** OD-4 enables a tier only with passing hardware evidence, and the owner stated on 2026-10-13 that Task 9's hardware evidence is not necessary for now. No evidence exists, so there is no RED policy test and no constant change. Cost if wrong: a tier stays on the static background until a bounded follow-up PR carries evidence.
7. **Branch base.** Branched from `origin/main` at f9c1897b because the local `main` was 34 commits behind. Cost if wrong: none; the owner merges.
8. **Pipeline note.** The first run of the gate pipeline stopped at a type error in my own spec (`Promise<void>` against Playwright's `Promise<Disposable>`) and an unused variable; both were fixed, the logs were cleared and the pipeline restarted on the committed tree. Nothing in this receipt comes from the aborted run.
