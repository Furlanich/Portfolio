# Structured findings register

[Audit and priorities](index.md) · [Copy evidence](copy-review.md) · [Browser evidence and screenshots](browser-evidence.md)

All directions are RECOMMENDATIONS / PROPOSED CHANGES. Current states are FACTS; commercial effects are FINDINGS. “Approval: yes” means the relevant owner must approve revised product/copy/design before implementation. “No new product decision” means restoring an already approved contract; it still needs an implementation PR and is not authorized in this audit. Unless stated otherwise, page findings apply to both locales. No finding upgrades evidence or approves wording.

Evidence shorthand: **H** = homepage runtime and locale `home.ts`; **S** = Services runtime and `services.ts`; **P** = Projects/detail runtime, `projects.ts`, `lib/projects/publication.ts`, item records; **ST** = Studio runtime and `studio.ts`; **F** = Founder runtime and `founder.ts`; **C** = Contact runtime, `contact.ts`, ContactForm/Page; **N** = SiteHeader, route composition and observed links; **D** = authoritative docs. Modules live in `app/(es)/_content/` and `app/(en)/en/_content/`. Viewport evidence is in the linked browser appendix; quoted-line identifiers refer to the copy appendix.
